## Présentation 📋

Chaque semaine un problème de la plateforme CodingGame sera résolu sur mon compte <a href="https://www.codingame.com/profile/4d24242bd9591391822242c053c103b30423507" style="color:#FFD200">Mkya21</a> et sera publié sur ce repo sous la forme : 
> 📁 [numéro de la semaine]-codingame 

avec l'arborescence suivante :

```
codingame-solutions/
├── C/
│ ├── semaine1-codingame/
│ ├── semaine2-codingame/
├── TypeScript/
│ ├── semaine1-codingame/
│ ├── semaine2-codingame/
└── README.md
```
